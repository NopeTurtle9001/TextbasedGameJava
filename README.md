# Text-Based Adventure Game

## Overview
This is a **Java-powered text-based adventure game** where players embark on a journey of survival, exploration, and combat in a vast, lore-rich world. Players can **travel between locations**, **fight enemies**, **enter dungeons**, and **level up** as they progress.

## Features
- **Character Creation**: Choose a name and class (Warrior, Knight, Ranger, etc.).
- **Exploration**: Travel between cities, dungeons, and landmarks.
- **Combat System**: Battle various enemies using strategic attacks or defense.
- **Dungeon Mechanics**: Enter dungeons to face tough encounters and bosses.
- **Save & Load**: Save progress to a file and continue your journey later.
